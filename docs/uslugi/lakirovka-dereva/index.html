Покрытие дерева лаком в Сануре

Покрываю лаком двери, мебель, столешницы, лестницы, полы и уличное дерево. Во влажном воздухе лак ведёт себя иначе: мутнеет, дольше сохнет, отслаивается при ошибках подготовки — поэтому работаю по погоде и с промежуточной шлифовкой.

  4. Нанесение лака в несколько слоёв
  5. Промежуточная шлифовка
  6. Лак для улицы с UV-защитой
